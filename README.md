## Run locally

```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

Built with Next.js and React. The project uses a static export so it can be hosted on Vercel, Netlify, GitHub Pages, or any static web host.
